Student Rental Hub
Student Rental Hub is a web-based rental management system designed for college and hostel students. It allows students to rent academic materials and essential items such as textbooks, notes, two-wheelers, cameras, printers, projectors, speakers, and other electronic equipment instead of purchasing them for short-term use.

How It Works
Students can log in to the platform, complete their profile, browse available rental items, view item details, select a rental duration, and place a rental request.
The system records rental, payment, and transaction information. Students can also view their rental history and submit ratings and review
An Admin can manage users and rental items and monitor rentals, ratings, statistics, and system activities.

Basic Flow
Login → Complete Profile → Browse Items → Select Item → Choose Rental Duration → Payment → Rental Confirmation → Track Rental → Review

Main Features
- Student and Admin login
- Student profile management
- Browse and search rental items
- Rental and booking management
- Payment and transaction records
- Rental history and due-date tracking
- Ratings and reviews
- Admin dashboard
- Activity logging

Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Server: Apache / XAMPP
- IDE: Visual Studio Code

Database
The project uses a MySQL database named:
"student_rental_hub"
It stores user, profile, rental, payment, rating, and activity information.

How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside:
   "C:\xampp\htdocs\"
4. Create the "student_rental_hub" database in phpMyAdmin.
5. Import the project database/SQL file.
6. Open the project in your browser through:
   "http://localhost/Student-Rental-Hub/"
